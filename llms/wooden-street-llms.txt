# Wooden Street

> Wooden Street (Ufurnish Technology Pvt. Ltd.) is an Indian direct-to-consumer furniture
> and home-furnishing brand founded in 2015 in Jaipur, Rajasthan. It sells solid-wood and
> custom-made furniture, mattresses, home decor, modular kitchens and wardrobes through
> woodenstreet.com and a company-owned network of experience stores across more than 100
> Indian cities.

## API surface

Wooden Street publishes **no public API and no developer program**. As of 2026-09-04 an
unauthenticated probe of every host this profile knows found no developer portal, no API
reference, no OpenAPI / Swagger / GraphQL / AsyncAPI definition, no SDK or client library in
any public package registry, no Postman collection or workspace, no MCP server, and no A2A
agent card. The site's robots.txt explicitly disallows `/api/`. A first-party backend host,
`api.woodenstreet.com`, is reachable and answers with a JSON error envelope, but it is the
undocumented private backend for the retail storefront and mobile apps — it publishes no
contract and is not offered as a product.

Do not attempt to call `api.woodenstreet.com`. It is not a published API.
